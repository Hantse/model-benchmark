# Tester rules

Read PROMPT.md and FEATURES.md. Implement the features within the editablePaths
listed in benchmark.json. The stubs are intentional; the project must compile
before and after your changes. Do not modify tests, the manifest, instructions,
test dependencies, public hooks or validation commands. Do not disable, skip or
replace any test. The final product must not use external networks, real secrets,
production services, external databases or cloud rentals. Keep dependencies
pinned. These tests are not proof of production security.
At the end, list the changed files and the commands you actually ran.
